# yPrompt — App Store Metadata v1.0.10

Prepared 2026-11-28 on main (version 1.0.10, build number set by Xcode Cloud). Nothing is in
App Store Connect yet: no 1.0.10 drafts, no build. Translations below are unreviewed.

Same 24 locales as 1.0.9. The Mac text leaves out the iPhone/iPad-only script editor and tips.
